# ai3d

Minimal Rust JSON scene compiler and Ghostty scratchpad bridge. Geometry is generated by the established `trimesh` Python library through a thin subprocess adapter (install with `scripts/setup_rasterminal.sh`), while the CLI remains Rust. `build` emits a valid GLB path, and `show`/`open` watch the JSON and rewrite the asset on save.

```sh
cargo run -- build examples/basic.json
cargo run -- open examples/basic.json
cargo run -- state
cargo run -- screenshot
```

Run `scripts/setup_rasterminal.sh` to clone pinned rasterminal HEAD and build it. The compiler keeps scene JSON canonical and deliberately has no labels or editor UI. Pane pixel screenshots are unsupported because Kitty graphics do not appear in PTY text; camera state is currently canonical scene state, pending upstream viewer state API.
